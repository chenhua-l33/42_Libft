# Description

This beginner project in C involves implementing a custom library in C.
- Part 1: string and memory primitives
- Part 2: string manipulation with memory allocation
- Part 3: linked list operations

# Instructions

## Build
make        # builds libft.a

make clean  # remove object files

make fclean # remove object files and libft.a

make re     # fclean + make
